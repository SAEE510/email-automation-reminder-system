\# Email Automation \& Reminder System



\## Project Overview

A Python-based student project that manages contacts,

scheduled reminders, personalized email templates,

email simulation, and activity reporting.



\## Technologies Used

\- Python

\- CSV

\- SMTP

\- Schedule

\- Pandas

\- Git and GitHub (publication planned)



\## Completed Features

1\. Contact management using CSV.

2\. Reminder data management using CSV.

3\. Contact and reminder validation.

4\. Reusable email templates.

5\. Automatic email personalization.

6\. Due and upcoming reminder detection.

7\. Email sending simulation.

8\. Optional SMTP integration (disabled by default).

9\. Activity logging and reporting.

10\. Duplicate reminder protection.

11\. Integrated main program.



\## Project Safety

\- Uses fictional sample contact data.

\- Email simulation is the default.

\- Actual SMTP sending is disabled.

\- Credentials are not stored in source code.
